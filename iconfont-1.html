字体图标

图标被做成一套字体文件，每个图形占用一个 Unicode 码位。页面里写一个字符、套上对应字体，浏览器就把这个字符画成图形——所以它能像文字一样被字号和颜色直接控制。

U+f6c8

它是怎么跑起来的

字体图标没有图片、没有 SVG，靠的是三件事配合：字体文件、码位映射、伪元素渲染。

字符即图形

每个图标在字体里占一个私有码位，比如房屋是 U+f015。写进 HTML 的其实只是一个普通字符。

伪元素输出

图标类通过 ::before 的 content 把这个字符输出，再指定 font-family 指向图标字体，字符就变成了图形。

跟随文字属性

因为它本质是字，所以 color 改颜色、font-size 改大小、vertical-align 调对齐，全都通用。

怎么用

引入一次样式表，之后只需要一个空标签加两个类名。

<!-- ① 引入本地字体图标样式（含 @font-face 与全部图标类） -->
<link rel="stylesheet" href="cdn/fontawesome/css/all.min.css">

<!-- ② 用一个空标签 + 样式类 + 图标名 -->
<i class="fa-solid fa-house"></i>
<i class="fa-regular fa-bell"></i>
<i class="fa-brands fa-github"></i>

/* ③ 当作文字来控制 */
.icon { color: #087f8c; font-size: 26px; }

字体图标与 SVG 的差别

两种方式都能做出图标，取舍点不一样。

对比项 字体图标 SVG
着色 只能整体单色，靠 color 控制 可多色，每个路径单独上色
缩放 改 font-size，矢量不失真 改 width/height，矢量不失真
请求数 一个字体文件承载全部图标 内联则零请求，外链则逐个请求
可控性 无法改图形内部细节 可改描边粗细、局部动画
无障碍 需手动加 aria-hidden 避免读屏误读 可写 title 与 role，语义更清楚
