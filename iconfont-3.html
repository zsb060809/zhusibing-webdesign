TABBAR / 字体图标

四个入口，
一条固定不动的底栏。

图标来自 iconfont.woff2，用 ::before 的 content 写 Unicode 码位渲染，可用 CSS 直接控制颜色与字号。

首页

默认选中项，图标底色为淡青圆角块。

发现

常规状态，图标与文字同为浅灰墨色。

消息 · 带数字徽章

右上角红色徽章，超过 99 折叠为 99+。

实现要点

  • 用 position: fixed + bottom: 0 让底栏脱离文档流常驻视口底部。
  • width: 100% 保证自适应；max-width 与内容列一致，桌面端不会拉成一条长带。
  • left: 50% 配合 translateX(-50%) 水平居中。
  • grid-template-columns: repeat(4, 1fr) 四项等分，增删项目只改一个数字。
  • padding-bottom: env(safe-area-inset-bottom) 避让 iPhone 底部小黑条。
  • 徽章父级设 position: relative，徽章用 position: absolute 定位到右上角。
<!-- 字体图标：类名 + 码位 -->
<a class="zsb_tab is_on" href="#">
  <span class="zsb_tab_mark">
    <i class="zsb_icon zsb_icon_home"></i>
  </span>
  <span class="zsb_tab_label">首页</span>
</a>

.zsb_icon_home::before { content: "\f015"; }
/* 底栏：固定 + 自适应宽度 */
.zsb_tabbar {
  position: fixed;
  left: 50%; transform: translateX(-50%);
  bottom: 0; width: 100%; max-width: 480px;
  display: grid; grid-template-columns: repeat(4, 1fr);
}
