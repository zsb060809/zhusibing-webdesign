二、第 1 轮提示词（原文）

用 Swiper 给 #wySw4 写一段初始化代码，要求：
1. 自动播放，3.2 秒换一张
2. 底部要有圆点分页器
3. 用立方体效果
4. 用户手动拖过之后不要停下来

直接给我可以粘贴的 new Swiper('#wySw4', { ... }) 代码。

AI 第 1 轮的返回

var swiper = new Swiper('#wySw4', {
  loop: true,
  effect: 'cube',
  autoplay: 3200,
  pagination: { el: '#wyPag4' }
});

这一版的四个漏洞

需求 AI 实际写的 问题
① 无循环 loop: true 方向写反了，我只说了"自动播放"，它就把默认补成循环
② 3.2 秒 autoplay: 3200 这是 Swiper 5 的旧写法，v11 里数字会被整个忽略，根本不自动播
② 拖动后继续 未写 缺 disableOnInteraction: false，默认 true → 一碰就停
③ 圆点可点 pagination: { el: '#wyPag4' } 少了 clickable: true，圆点只能看不能点
④ cube effect: 'cube' 这条是对的

另外还漏了 speed：没写就走默认 300ms，cube 转得太急，看起来像"闪一下"。

三、第 2 轮提示词（原文，最终采用）

你上一版有三处不符合要求，按下面逐条改，改完每条给出对应参数：

1. 版本：Swiper 11，用 swiper-bundle，初始化对象写法。
2. 不要循环：不要写 loop，翻到最后一张就停，不要绕回第一张。
3. 自动播放 3.2 秒，并且用户拖动松手后要继续播，不要停 —— 请用 autoplay 对象的 delay
   和 disableOnInteraction 两个参数实现。
4. 分页器用 #wyPag4，必须能点圆点跳转，把 clickable 明确写出来。
5. 初始效果 cube，切换速度 800ms。
6. 输出完整代码，并在每个参数后面用一行注释说明它对应上面第几条。

AI 第 2 轮的返回（最终采用）

new Swiper('#wySw4', {
  speed: 800,                              // 第 5 条：切换 800ms
  effect: 'cube',                          // 第 5 条：初始立方体
  // 第 2 条：这里刻意不写 loop，保持默认 false
  autoplay: {
    delay: 3200,                           // 第 3 条：3.2 秒一张
    disableOnInteraction: false            // 第 3 条：拖动后继续自动播放
  },
  pagination: {
    el: '#wyPag4',                         // 第 4 条：圆点容器
    clickable: true                        // 第 4 条：点圆点可跳转
  }
});

两轮之间到底改了什么

改动 第 1 轮 第 2 轮 为什么
循环 loop: true 整行删掉 "不要循环"必须写成否定指令，不能只是"没提"
自动播放 autoplay: 3200 autoplay: { delay: 3200, disableOnInteraction: false } v11 里 autoplay 是对象，光写数字会被忽略
分页器 pagination: { el: '#wyPag4' } 加 clickable: true 题只说"圆点分页器"，没说要能点，得补
切换速度 未写（默认 300ms） speed: 800 让 cube 翻转看得清
版本约束 未声明 "Swiper 11，用 swiper-bundle" 不声明版本，它就按训练数据里的旧版本写

五、答辩三问

问 1：你的第一版提示词漏掉了哪个需求？

最明显的是 "不要循环"。我第一轮只说"自动播放、圆点、立方体、拖动后不停"，默认"没说就是不要"， 但 AI 的默认是"没说就给你 loop: true"——它见过的轮播绝大多数都是循环的。

第二个是 "圆点要能点"：只说了"要有圆点分页器"，AI 就只给了容器。

还漏了 Swiper 版本：没说版本，它按旧版本写成了 autoplay: 3200。

问 2：你是怎么在第二轮里"说清楚"的？

三件事：

  1. 把否定需求写成否定指令——不说"我需要无循环"，而是直接写"不要写 loop，翻到最后一张就停，不要绕回第一张"；
  2. 把效果翻译成参数名——不说"拖动后继续"，而是说"用 autoplay 对象的 delay 和 disableOnInteraction 两个参数实现"；
  3. 加输出格式约束——声明版本，并要求每个参数后面用注释标明对应第几条，这样它没法自由发挥，我也能一眼核对。

问 3：AI 第一次给的代码错在哪？

四处：loop: true 方向写反；autoplay: 3200 是旧写法、v11 不认；缺 disableOnInteraction: false 导致手一碰就停；缺 clickable: true 导致圆点不能点。 另外没写 speed，cube 转得太快。

六、结论

第一轮提示词写的是"我想要什么"，第二轮写的是"哪一条、用什么参数、不要什么"。 AI 不会读心，它只会按概率补全——所有"默认不要"的东西都必须显式说成"不要"，所有"要"的东西最好落到具体参数名上。
