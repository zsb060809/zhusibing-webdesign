SVG 图标

图标本身就是一段矢量图形描述。Lucide 在运行时把占位标签替换成真正的 svg 标签，图形以描边方式绘制，粗细、端点、颜色都能单独调整。

viewBox 0 0 24 24

它是怎么跑起来的

SVG 不靠字体，靠的是矢量描述加运行时替换。

路径描述形状

每个图标是一组 path、circle、line，按 24×24 的坐标系画出轮廓，不依赖任何字体文件。

描边而非填充

Lucide 用 stroke 画线、fill 设为 none，所以线条粗细干净统一，放大后不会糊。

属性随时可调

stroke-width、stroke-linecap、color 都是普通 CSS 属性，改一个值，整组图标跟着变。

只有 SVG 做得到的事

拖动滑块改变描边粗细——这是字体图标做不到的，因为它只能整体缩放。

1.75

滑块修改的是 CSS 变量，四个图标同时响应。字体图标要达到类似效果只能换一套字重不同的字体文件。

怎么用

引入脚本，写占位标签，最后调用一次生成。

<!-- ① 引入本地 Lucide 脚本 -->
<script src="cdn/lucide/lucide.min.js"></script>

<!-- ② 用 data-lucide 写占位标签 -->
<i data-lucide="house"></i>
<i data-lucide="compass"></i>

// ③ 页面加载后一次性替换成真 SVG
lucide.createIcons();

/* ④ 之后它就是一个普通 svg，可以按 CSS 控制 */
svg { stroke-width: 1.75; color: #e97843; }

SVG 与字体图标的差别

同一件事的两种做法，取舍点不同。

对比项 SVG 字体图标
着色 可多色，每条路径单独上色 只能整体单色
线条控制 描边粗细、端点形状都能调 受字体本身设计约束
网络请求 内联零请求；用脚本库则需先加载库 一个字体文件即可
语义 可加 title、role，读屏更友好 是字符，容易被读屏念成乱码
动画 可做路径描边、局部变形 只能整体旋转或变色
