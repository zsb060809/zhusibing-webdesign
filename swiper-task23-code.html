任务二 · creative 仿写（课堂没讲的效果）

1. 官方示例里的一句话

官方 demos/257-effect-creative.html 的思路只有一句： creativeEffect 里的 prev 和 next，分别描述"上一张此刻停在哪、下一张此刻停在哪"。

属性 管什么 我的取值 视觉结果
translate 位移，[x, y, z] prev ['-55%', 0, -120]
next ['55%', 0, -40]		 上一张往左移开并后退，下一张从右后方靠过来
rotate 旋转，[x, y, z] 角度 prev [0, 0, -10]
next [0, 0, 6]		 上一张逆时针歪 10°，下一张顺时针歪 6°
scale 缩放 prev 0.8 / next 1.08 上一张缩小、下一张放大，形成"抽卡"的层次
opacity / shadow 透明度 / 投影 prev 0.9，两边都开 shadow 上一张略微变暗，卡片有厚度

2. 完整初始化代码（js/zsb_swiper_p2.js 核心段）

var zsb_rotate_z = -10;      // 上一张的 Z 轴角度，按钮会改这个值

function zsb_build() {
  var zsb_el = document.querySelector('#zsbSw2');
  if (!zsb_el || typeof window.Swiper !== 'function') {
    return null;
  }

  return new window.Swiper('#zsbSw2', {
    loop: true,
    speed: 600,
    grabCursor: true,
    effect: 'creative',
    creativeEffect: {
      prev: {                                   // 上一张停在哪
        translate: ['-55%', 0, -120],           // 向左移出 55%，并后退 120px
        rotate: [0, 0, zsb_rotate_z],           // 逆时针歪（默认 -10°）
        scale: 0.8,                             // 缩小到 80%
        opacity: 0.9,
        shadow: true
      },
      next: {                                   // 下一张停在哪
        translate: ['55%', 0, -40],             // 在右后方 55% 处待命
        rotate: [0, 0, 6],                      // 顺时针歪 6°
        scale: 1.08,                            // 放大 8%，形成"冒头"感
        shadow: true
      }
    },
    pagination: { el: '#zsbPag2', clickable: true },
    navigation: { prevEl: '#zsbPrev2', nextEl: '#zsbNext2' }
  });
}

3. 追问"改成 20 度"怎么实现

creativeEffect 在初始化时就已经算成 transform 写进样式了，创建后不能再改参数，所以做法是销毁 + 重建：

function zsb_switch_rotate(zsb_value, zsb_button) {
  zsb_rotate_z = zsb_value;                       // 换角度

  // 先清掉所有按钮的选中态，再把当前按钮点亮
  document.querySelectorAll('.zsb_btns .zsb_btn').forEach(function (zsb_item) {
    zsb_item.classList.remove('zsb_on');
  });
  if (zsb_button) { zsb_button.classList.add('zsb_on'); }

  if (zsb_swiper && !zsb_swiper.destroyed) {
    zsb_swiper.destroy(true, true);               // 连 DOM 上的样式一起清掉
  }
  zsb_swiper = zsb_build();                       // 用新角度重建
}

4. 答辩两问

问：transform 里的百分比是相对谁的？
相对元素自身的宽高，不是相对父容器。translate: ['-55%', 0, -120] 意思是"往左挪自身宽度的 55%"，所以无论轮播容器多宽，卡片露出的比例始终一样，换屏幕尺寸不会错位。 另外 translate 的第三个数 z 是像素，不是百分比——百分比只能用在 x 和 y 上，z 轴没有"自身厚度"可参照。

问：改一个数值让卡片转 20 度，怎么做？
改 creativeEffect.prev.rotate 的第三个值（Z 轴）。注意两件事： ① 改完必须重建实例，因为 transform 在初始化时就算好了； ② 20° 时上一张的边角会明显翘起，配合 scale: 0.8 才看得出"歪着缩到后面"的立体感。 所以页面上把"默认 -10°"和"20°"做成了两个按钮，点一下就能对比。

2. 完整初始化代码（js/zsb_swiper_p3.js）

function zsb_build() {
  var zsb_el = document.querySelector('#zsbExpo');

  if (!zsb_el || typeof window.Swiper !== 'function') {
    return null;
  }

  return new window.Swiper('#zsbExpo', {
    loop: true,          // 六张展品首尾相接
    speed: 900,          // 一次切换 900ms，比默认慢，更有"展厅"的从容感
    parallax: true,      // 打开视差

    keyboard: {
      enabled: true,          // 方向键 ← → 可以翻页
      onlyInViewport: true    // 轮播不在视口里时不抢键盘事件
    },

    autoplay: {
      delay: zsb_default_delay,          // 4200ms
      disableOnInteraction: false        // 手动翻页后自动播放继续
    },

    pagination: { el: '.swiper-pagination', clickable: true },
    navigation: { prevEl: '.swiper-button-prev', nextEl: '.swiper-button-next' }
  });
}

规则很好记：负得越多，移动得越快。编号 -200 几乎跟着图片走，标题 -380 快一档，正文 -560 更快，日期 -700 最快—— 翻页时文字像被风扯着往前冲，图片却慢悠悠地平移，前后层次就出来了。

4. 现场改 delay 的按钮

function zsb_set_delay(zsb_value, zsb_button) {
  // 先清全部选中态，再点亮当前按钮
  document.querySelectorAll('.zsb_controls button').forEach(function (zsb_item) {
    zsb_item.classList.remove('zsb_on');
  });
  if (zsb_button) { zsb_button.classList.add('zsb_on'); }

  if (!zsb_swiper || zsb_swiper.destroyed) { return; }

  zsb_swiper.params.autoplay.delay = zsb_value;   // 改参数
  zsb_swiper.autoplay.stop();                     // 停 → 起，新间隔才立刻生效
  zsb_swiper.autoplay.start();
}

5. 答辩四问

问 1：这段代码是什么意思？
new Swiper('#zsbExpo', {...}) 是初始化。loop 让六张展品首尾相接； speed: 900 是一次切换动画 900ms；parallax: true 打开视差（让带 data-swiper-parallax 的元素按比例错位移动）；keyboard 接管键盘方向键； autoplay.delay 是每张停留时间；pagination / navigation 只是把页面上已有的圆点和左右箭头接上。

问 2：AI 第一次给的哪里不对，你改了什么？
两处。① 类名自创——它把标题层写成 <div class="caption">， 和原有五张的 .zsb_expo_cap 不一致，直接粘进去第六张就会掉样式；我要求它沿用 .zsb_expo_cap，内部结构是 span.zsb_expo_no + h2 + p + div.zsb_meta，和前面五张一模一样。 ② keyboard 写法错——它写的是 keyboard: true，Swiper 11 里不生效，必须是对象； 我改成 keyboard: { enabled: true, onlyInViewport: true }。

问 3：新参数的作用？
keyboard.enabled：允许方向键左右翻页； keyboard.onlyInViewport：只有轮播在可视区域时才响应键盘，避免页面滚到别处按方向键也被"吃掉"； parallax 与 data-swiper-parallax="-380"：元素随滑动做反向位移， 数值绝对值越大移动越快，形成"图片慢、文字快"的层次。

问 4：现场把 delay 改成指定值，预期会怎么变？
改成 1500：每张只停 1.5 秒，切换显得急促，适合图片少、信息简单的场景； 改成 5000：每张停 5 秒，节奏放慢，适合有长文案需要阅读的场景。 代码层面改的是 swiper.params.autoplay.delay，改完必须 stop() 再 start() 一次——因为 autoplay 的定时器在启动那一刻就按旧值排好了， 只改参数要等这一轮走完才换新间隔。页面上那三个按钮就是这么实现的，点一下立刻能看到节奏变化。
