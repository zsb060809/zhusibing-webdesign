任 务 一 · 提 示 词 工 程 师

让 AI 听懂需求：#wySw4 的 cube 轮播

同一件事，第一轮提示词说的是"我想要什么"，第二轮提示词说的是"哪一条、用什么参数、不要什么"。差别就体现在 AI 交回来的代码上。

两轮提示词逐项验证答辩三问

一、这一轮要 AI 产出什么题目给出的四条硬性需求

编号 需求 对应 Swiper 参数
① 无循环播放（翻到最后一张就停住） 不写 loop（默认 false）
② 3.2 秒自动翻页，手动操作后不停止 autoplay.delay: 3200 + disableOnInteraction: false
③ 圆点分页器可点击跳转 pagination.clickable: true
④ 初始效果为立方体 effect: 'cube'

要求：至少两轮提示词，第一轮允许有遗漏，但要保留每轮提示词与 AI 的回答，逐项验证。

二、第 1 轮提示词只描述了"想要什么"

用 Swiper 给 #wySw4 写一段初始化代码，要求： 1. 自动播放，3.2 秒换一张 2. 底部要有圆点分页器 3. 用立方体效果 4. 用户手动拖过之后不要停下来 直接给我可以粘贴的 new Swiper('#wySw4', { ... }) 代码。

AI 第一轮的返回（节选）

var swiper = new Swiper('#wySw4', { loop: true, effect: 'cube', autoplay: 3200, pagination: { el: '#wyPag4' } });

这段代码一眼能看出的问题

需求 代码实际写的 问题
① loop: true 写反了，需求是"无循环"
② autoplay: 3200 这是 Swiper 5 的老写法，v11 要写成对象
② 没有 disableOnInteraction v11 默认是 true，拖动一下自动播放就停了
③ pagination 只有 el 没写 clickable，"可点击"没有任何体现

三、第 2 轮提示词把需求翻译成参数，并且明确说"不要什么"

你上一版有三处不符合要求，按下面逐条改，改完每条给出对应参数： 1. 版本：Swiper 11，用 swiper-bundle，初始化对象写法。 2. 不要循环：不要写 loop，翻到最后一张就停，不要绕回第一张。 3. 自动播放 3.2 秒，并且用户拖动松手后要继续播，不要停 —— 请用 autoplay 对象的 delay 和 disableOnInteraction 两个参数实现。 4. 分页器用 #wyPag4，必须能点圆点跳转，把 clickable 明确写出来。 5. 初始效果 cube，切换速度 800ms。 6. 输出完整代码，并在每个参数后面用一行注释说明它对应上面第几条。

AI 第二轮的返回（最终采用）

new Swiper('#wySw4', { speed: 800, // 第 5 条：切换 800ms effect: 'cube', // 第 5 条：初始立方体 // 第 2 条：这里刻意不写 loop，保持默认 false autoplay: { delay: 3200, // 第 3 条：3.2 秒一张 disableOnInteraction: false // 第 3 条：拖动后继续自动播放 }, pagination: { el: '#wyPag4', // 第 4 条：圆点容器 clickable: true // 第 4 条：点圆点可跳转 } });

第二轮的关键变化：把"不要循环"写成了明确的否定指令（不要写 loop），把"拖动后不停"翻译成了具体参数名，还要求 AI 逐条对应，避免它自由发挥。

四、逐项验证下面这个轮播就是上面那段代码跑出来的

验证台 · 无循环 + 3.2 秒自动 + 圆点可点 + cube

需求 怎么验 结果 一句话结论
① 点最后一个圆点，等自动播放再走一轮 停在 5/5 不动 没有 loop，翻到底就停。
② 什么都不做，掐表看两张之间的间隔；再拖动一次看是否继续 约 3.2 秒一张，拖动后继续 delay 与 disableOnInteraction 都生效。
③ 直接点第 3 个圆点 跳转到 3/5 clickable: true 生效。
④ 刷新页面看首屏切换动作 立方体翻转 effect: 'cube' 生效。

五、答辩三个问题的书面回答

问 1：你的第一版提示词漏掉了哪个需求？

漏在"不要循环"这一条——我只写了四条要什么，没有写"不要什么"，AI 就按轮播的常见习惯默认给了 loop: true。 另外"拖动后不要停"我只说了自然语言，没给出参数落点，AI 用了旧版本的 autoplay: 3200，等于把需求丢了。

问 2：你是怎么在第二轮里"说清楚"的？

做了四件事：①锁定版本（Swiper 11，避免它给旧写法）；②每条需求编号（第 1～6 条），要求 AI 逐条对应； ③把自然语言翻译成参数名（delay / disableOnInteraction / clickable）；④明确写否定项（不要写 loop）， 并且要求"每个参数后面注释它对应第几条"，这样它没法含糊过去。

问 3：AI 第一次给的代码错在哪？

三处：① loop: true 与"无循环"完全相反，属于把需求理解反了； ② autoplay: 3200 是 v5 的数字写法，v11 必须是对象，而且没有 disableOnInteraction: false，拖动后会自动停； ③ pagination 只写了 el，没有 clickable，虽然 v11 默认是 true，但代码里没有任何地方能证明它满足"可点击"这条要求。
