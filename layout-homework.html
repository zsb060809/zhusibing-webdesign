网页整体布局 · 课后作业答案

第一部分：看代码找错（3 处 bug）

作业给的原始代码（原样）：

<style>
  .box li{ width: 300px; }
  .box img{ width: 100%; }
  .box li:hover img{ transform: scale(1.2); transition: all .6s; }
  .txt{ position: absolute; bottom: 0; height: 40px; background: rgba(0,0,0,.6); }
  .box{ display: flex; }
</style>
Bug 1（现象：图片放大跑出卡片，盖住旁边卡片）
原因：li 上没有 overflow:hidden，图片 scale(1.2) 放大后超出 li 的部分没被裁掉，就压到右边卡片上了。
改法：给 li 加 overflow:hidden。
.box li { overflow: hidden; }
Bug 2（现象：文字展开只有移入有动画，移出没过渡）
原因：transition 写在了 .box li:hover img 上，意思是"进入 hover 那一刻"才有过渡；鼠标移开回到默认状态时没有过渡规则，所以瞬间恢复。
改法：把 transition 移到默认的 .box li img 上。
.box li img { width:100%; transition: transform .6s; }
.box li:hover img { transform: scale(1.2); }
Bug 3（现象：卡片布局排版错乱）
原因：.box{display:flex} 写在外层 .box 上，但 li 的真正父级是 ul，flex 根本没作用到 li，li 还是按默认块级竖着排，就乱了。
改法：让 li 的直接父级（ul）成为 flex 容器。
.box ul { display:flex; flex-wrap:wrap; gap:16px; list-style:none; padding:0; }

2.2 卡片动画补全

需要实现的效果关键 CSS / 答案
防止放大图片溢出 li 容器overflow: hidden（写在 li 上）
子绝父相，让文字条定位在卡片底部position: relative（写在 li 上，给 .txt 当父级参照）
hover 图片从原大放大到 scale(1.2)要写两个选择器：.box li img（默认）和 .box li:hover img
文字高度平滑展开，移入移出都有动画transition 写在默认（普通）选择器上；因为写在 :hover 上只有移入有动画，移出是瞬间的
奇数卡片悬浮，文字铺满整张卡片伪类选择器 :nth-child(odd)，即 .box li:nth-child(odd):hover .txt { height:100%; }

2.3 flex 两栏布局填空

  • 父容器开启 flex：display: flex
  • 设置两栏间隙 8px：gap: 8px（作业明确禁止用 margin）

我算了一下：792（主）+ 400（侧）+ 8（间隔）= 1200，正好等于版心宽度，所以两栏并排刚好满版心。

第三部分：手写原理简答

  1. 画图：父 position:relative，子 position:absolute 的盒子关系

    父设了 relative 之后，子元素 absolute 的 top/right/bottom/left 就都相对"父的边框"来定位，不会乱跑去贴浏览器边缘。

  2. overflow:hidden 本节课两个作用
    • 作用 1：把超出容器边框的内容裁掉（hidden），图片放大后多出来的部分直接看不见。
    • 作用 2：配合缩放动画，把"动"的范围框死在卡片里，不影响旁边布局。
  3. transform:scale(1.2) 会不会把盒子实际占位变大、挤压旁边卡片？
    不会。transform 只改"画出来"的样子（视觉渲染），不改元素在文档流里的占位盒子，所以旁边卡片的位置一点不变。
  4. transition 写在 hover 上 vs 写普通选择器上，移出动画的区别？
    写在普通选择器（默认状态）上：移入和移出都走过渡，都有动画；写在 :hover 上：只有移入那一下有过渡，移出是瞬间的。所以作业里我把它写在默认 .box li img 上。
  5. 记录自己写代码遇到的 1 个 bug（≥30 字）
    做卡片时图片放大后盖住了右边卡片，排查发现是给 li 加 overflow 时写成了 overflow:auto 还漏了，后来改成 hidden，图片就被裁在卡片里，旁边卡片也不被挡了。

第四部分：扩展挑战（纯 CSS 回到顶部）

左下角那个蓝色圆圈就是，纯 CSS 没写 JS：

  • position: fixed 固定在视口左下角（left:20px; bottom:20px）；
  • 初始 opacity: .5 半透明；
  • :hover 时 opacity: 1 完全不透明，同时 transform: scale(1.1) 轻微放大；
  • z-index: 999 保证浮在页面内容之上；
  • 点击靠锚点 <a href="#top"> 回到页面顶部。
#backTop{
  position: fixed; left: 20px; bottom: 20px;
  width: 50px; height: 50px; border-radius: 50%;
  background: #5b6cff; color: #fff; opacity: .5;
  z-index: 999; transition: all .3s;
}
#backTop:hover{ opacity: 1; transform: scale(1.1); }
