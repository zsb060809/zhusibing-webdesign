zsb
TABBAR / 内联 SVG

同一条底栏，
换成矢量描边图标。

图标以 <symbol> 定义一次、<use> 复用；描边粗细、颜色都能用 CSS 直接改，不依赖字体文件。

描边粗细 当前 1.75 px

首页

选中态：暖橙描边配浅橙圆角底。

发现

常规态：图标继承父级文字色，无需改文件。

消息 · 带数字徽章

徽章是真 DOM 元素，数字可由后端直接渲染。

实现要点

  • 用 <symbol> 集中定义图形，<use href="#id"> 复用，一个图标只写一遍路径。
  • 路径统一 fill="none" stroke="currentColor"，颜色跟着父级文字色走。
  • 描边粗细交给 CSS 变量 --zsb_stroke，滑杆改的是这一个变量。
  • 底栏同样是 position: fixed + width: 100% + max-width，固定且自适应。
  • SVG 不请求字体文件，不存在图标加载空白期，也不受 font-size 基线影响。
<!-- 1) 定义：整页只写一次 -->
<svg class="zsb_sprite">
  <symbol id="zsb_i_home" viewBox="0 0 24 24">
    <path d="M3 10a2 2 0 0 1 .709-1.528l7-5.999..."/>
  </symbol>
</svg>

<!-- 2) 使用 -->
<svg class="zsb_svg"><use href="#zsb_i_home"></use></svg>

.zsb_svg {
  fill: none; stroke: currentColor;
  stroke-width: var(--zsb_stroke);
}
