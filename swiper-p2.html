第 7 种效果：creative 自定义变换

slide / fade / cube / coverflow / flip / cards 是 Swiper 内置的 6 种。第 7 种 creative 不给现成模板， 而是让你分别描述"上一张停在哪、下一张停在哪"，中间过程由 Swiper 自动补间。

prev / next 双描述缩小左移带角度放大右移答辩：百分号相对谁

一、效果要求照着题目描述写 transform

位置 视觉要求 实现手段
上一张（prev） 缩小、向左移、带一点角度 scale + 负的 translate + rotate
下一张（next） 放大、向右移 scale 大于 1 + 正的 translate
new Swiper('#zsbSw2', { effect: 'creative', creativeEffect: { prev: { // 上一张：缩到 0.8、往左挪 55%、逆时针歪 10° translate: ['-55%', 0, -120], rotate: [0, 0, -10], scale: 0.8, opacity: .9, shadow: true }, next: { // 下一张：放大到 1.08、往右挪 55% translate: ['55%', 0, -40], rotate: [0, 0, 6], scale: 1.08, shadow: true } } });

三、prev / next 的 transform 各控制什么用自己的话写下来

属性 prev（上一张） next（下一张）
translate 把上一张往左推、往后（z 轴负值）压，制造"退到后面"的纵深感 把下一张往右推，让它从右侧排队等进来
rotate 绕 Z 轴逆时针歪一点（负角度），像卡片被甩到一边 绕 Z 轴轻微顺时针，角度比 prev 小，显得更"正"
scale 小于 1，缩小，强化"已经翻过去"的层次 大于 1，放大，强调"即将上场"
opacity 略微变淡 保持清晰
shadow 加投影，脱离背景 加投影

一句话：prev 描述"旧的一张退场时停在哪"，next 描述"新的一张候场时待在哪"，当前这一张永远是 translate 为 0、scale 为 1 的原位。

四、答辩两个追问

问 1：transform 里的百分号，是相对谁算的？

相对这一张幻灯片自身的尺寸，和父容器、和屏幕都无关：translate 的水平方向 100% = 一张幻灯片的宽度， 垂直方向 100% = 一张幻灯片的高度。所以 ['-55%', 0, -120] 的意思是"往左挪半张多一点，同时往后压 120 像素"。 注意 z 轴没有百分比可用，只能写像素值。

问 2：改一个数值，让卡片转 20 度，怎么做？

把 rotate 的第三个数值（绕 Z 轴的角度）从 -10 改成 20： rotate: [0, 0, 20]。上面那个「追问版」按钮就是把 prev 的 rotate 换成 20° 后重建实例的效果—— 卡片明显歪得更多了。如果想让下一张反向歪，就把 next 的 rotate 改成 [0, 0, -20]。
